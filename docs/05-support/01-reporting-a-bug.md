# Reporting a Problem

If FishEye isn't behaving as expected, first check
[Troubleshooting](../04-troubleshooting/01-troubleshooting.md) — your issue
may already have a fix there. Otherwise, please
[open a bug report](https://github.com/fisheye-sonar/fisheye-ui/issues/new?template=bug_report.yaml)
on GitHub.

Please include:

- Your operating system (Windows or macOS)
- Your FishEye version
- What you were trying to do
- What you expected to happen
- What actually happened
- Any error message you received, including the log from the **Show
  log** panel on the progress screen if the problem happened during
  processing
- A screenshot, if possible

Please don't upload sonar data publicly unless you're comfortable sharing it.
