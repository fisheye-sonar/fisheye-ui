# Quick Start

This guide walks you through processing your first ARIS or DIDSON file with
FishEye.

## 1. Open FishEye

Launch FishEye from your Applications folder on macOS or the Start menu on
Windows.

## 2. Select your input

Choose an ARIS (`.aris`) or DIDSON (`.ddf`) file, or select a folder containing
multiple files. FishEye will process every supported file in the folder.

## 3. Select a model

The dropdown is already set to the recommended default, **YOLOv5m v0**. To learn
about the other options, see [Choosing a Model](02-choosing-a-model.md).

## 4. Choose where to save results (optional)

By default, FishEye saves results in the same folder as your input file. If
you'd rather save them somewhere else, enter an output folder under **Advanced
options**.

## 5. Run FishEye

Click **Run inference** to begin processing. You'll see a live progress screen
while FishEye works.

Processing time depends on the size of your files and your computer's hardware
(see [Recommended Hardware](../01-installation/01-recommended-hardware.md)).
Larger files and folders with many files take longer.

## 6. View your results

When processing finishes, FishEye shows a summary of fish counts right in the
app, and the result files are saved to your output folder. See
[Understanding Your Results](../03-results/01-understanding-results.md) and
[Output Files](../03-results/02-output-files.md) for details on what you'll get.
